# 管理员账号与帖子软删除设计

## 目标

增加可直接初始化的管理员账号，并让管理员能够删除和恢复帖子。删除采用软删除，保留帖子、图片关联、认领和评论数据。

## 数据与状态

- `posts.status` 增加 `DELETED` 枚举值。
- `database/04_interactions.sql` 保留现有点赞/收藏表，并新增管理员账号初始化语句。
- 管理员账号使用 bcrypt 密码哈希，不在 SQL 中保存明文密码；SQL 通过 `ON DUPLICATE KEY UPDATE` 保证可重复执行。
- 普通列表不返回 `DELETED` 帖子；管理员列表可按状态查看全部帖子。

## API

- `DELETE /api/v1/admin/posts/:id`：管理员软删除帖子，将状态改为 `DELETED`。
- `PUT /api/v1/admin/posts/:id/restore`：管理员恢复帖子，将状态改为 `ACTIVE`。
- 两个接口均要求登录用户 `is_admin = 1`，普通用户返回 403。
- 删除/恢复操作幂等：目标已处于目标状态时仍返回成功，并返回最新帖子状态。

## 客户端

- 管理员界面增加帖子管理入口，展示标题、发布者、状态。
- `ACTIVE/RESOLVED/CLOSED` 帖子显示“删除”，`DELETED` 帖子显示“恢复”。
- 操作成功后立即刷新管理员帖子列表；失败显示可读错误。
- 普通用户首页不展示已删除帖子。

## 验证

- SQL 可重复执行且管理员账号可登录。
- 后端测试覆盖管理员鉴权、删除、恢复和普通用户禁止访问。
- ArkTS 编译通过，管理员页面可操作删除/恢复，普通用户看不到已删除帖子。
